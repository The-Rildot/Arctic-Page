## When you replace or add files

- Prefer **reasonable dimensions** for stills (e.g. 1200–1600px wide) so GitHub renders clearly without multi‑megabyte PNGs; recompress with your editor or `oxipng` / similar if needed.
- **GIFs** grow quickly; trim duration, lower frame rate, or reduce palette so each file stays easy to clone (aim well under **~5–10MB** per GIF unless you have a strong reason).
- If you **rename** a file, update [README.md](../../README.md) (Screenshots section) and any other doc that embeds it.
